# 🌡️ Urban Heat Island Detection and Analysis System

A full-stack web application for detecting, analyzing, and visualizing Urban Heat Island (UHI) effects across 9 major Indian cities using Landsat 8 satellite imagery and a K-Means + Random Forest machine learning pipeline.

---

## 🏙️ Supported Cities

| City | City | City |
|------|------|------|
| Bengaluru | Hyderabad | Mumbai |
| Delhi | Chennai | Mangaluru |
| Ahmedabad | Kolkata | Pune |

Satellite data covers **Jan 2022 – Dec 2023** (Landsat 8, cloud cover < 20%).

---

## ⚙️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Satellite Data | Google Earth Engine — Landsat 8 Collection 2 Level-2 |
| ML Models | scikit-learn — K-Means (4 clusters) + Random Forest (100 trees) |
| Backend | Flask + Flask-CORS |
| Frontend | Vanilla HTML + CSS + JavaScript (single `index.html`) |
| Map | Leaflet.js |
| Charts | Chart.js |

## 🧠 ML Pipeline

```
Landsat 8 (Google Earth Engine)
        │
        ▼
  LST extraction from Band 10 (Thermal Infrared)
  NDVI = (B5 - B4) / (B5 + B4)
  NDBI = (B6 - B5) / (B6 + B5)
  FVC  = derived from NDVI
        │
        ▼
  Data Cleaning
  (LST: 15–55 °C | NDVI: −0.3 to 1.0)
        │
        ▼
  K-Means Clustering (k=4)
  Clusters ranked by average LST → heat zones
        │
        ▼
  Random Forest Classifier (100 trees, max_depth=10)
  Trained on K-Means labels
        │
        ▼
  GeoJSON + Stats JSON
        │
        ▼
  Flask API → Leaflet.js Map + Chart.js Charts
```

### Heat Zone Labels

| Zone | Label | Color | Typical LST (Bengaluru) |
|------|-------|-------|------------------------|
| 0 | Low | 🟢 Green | ~25 °C — dense vegetation |
| 1 | Moderate | 🟡 Yellow | ~30 °C — parks / residential green |
| 2 | High | 🟠 Orange | ~36 °C — residential / mixed urban |
| 3 | Critical | 🔴 Red | ~42 °C — industrial / commercial hotspot |

### Features Used

| Feature | Description |
|---------|-------------|
| `lst` | Land Surface Temperature (°C) |
| `ndvi` | Normalized Difference Vegetation Index |
| `ndbi` | Normalized Difference Built-up Index |
| `fvc` | Fractional Vegetation Cover |

## 🌐 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Serves `index.html` |
| GET | `/api/health` | Health check |
| GET | `/api/cities` | List all 9 cities with data availability |
| GET | `/api/stats?city=bengaluru` | Dashboard stats (avg LST, risk distribution) |
| GET | `/api/heatmap?city=bengaluru` | GeoJSON heatmap (optional `&risk=Critical` filter) |
| GET | `/api/feature-importance?city=bengaluru` | RF feature importances for bar chart |
| GET | `/api/mitigation/<risk_level>` | Mitigation suggestions (Low/Moderate/High/Critical) |
| POST | `/api/predict` | Predict heat zone for a custom pixel |

**Predict endpoint example:**
```json
POST /api/predict
{
  "city": "delhi",
  "lst": 38.5,
  "ndvi": 0.12,
  "ndbi": 0.18,
  "fvc": 0.08
}
```
Response:
```json
{ "heat_zone": 2, "risk": "High", "city": "delhi" }
```

## 🚀 Setup & Usage

### Prerequisites
- Python 3.9+
- Google Earth Engine account (only needed if re-extracting data)

### Step 1 — Install Dependencies
```bash
pip install -r requirements.txt
```

> For GEE data extraction, also install:
> ```bash
> pip install earthengine-api geemap
> earthengine authenticate
> ```

### Step 2 — Prepare City Data (run once)
Place `India_9Cities_UHI_ML_Dataset.csv` in the project root, then:
```bash
python prepare_cities.py
```
This splits the CSV per city, runs the full ML pipeline, and generates all `data/` and `ml/models/` files.

> **Skip this step** if the `data/` and `ml/models/` folders already exist (they're included if you received the full project).

### Step 3 — Start the Flask Backend
```bash
python app.py
```
API runs at: `http://localhost:5000`

### Step 4 — Open the Frontend
Open `index.html` directly in your browser — no additional server needed.
